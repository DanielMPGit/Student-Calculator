## 📖 Student Calculator

A classroom management application built in Java. It allows teachers or students to manage students and subjects, including adding/removing students, assigning subjects, tracking grades (exams, practicals, and additional), calculating grade averages, and monitoring attendance. Data is persisted using a local SQLite database, and navigation is handled through an interactive arrow-key menu powered by JLine3.
